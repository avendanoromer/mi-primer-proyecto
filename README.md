# Mi primer proyecto

Este es un repositorio de práctica para aprender el flujo de trabajo de GitHub: ramas, commits y Pull Requests.

## Sobre este proyecto

Creado por Romer Avendaño para practicar cómo se envía un Pull Request en GitHub.

## Flujo de trabajo

1. Crear una rama nueva para el cambio.
2. Hacer commits pequeños y descriptivos.
3. Abrir un Pull Request para revisar los cambios antes de fusionarlos a `main`.
